Hi! Welcome to my portfolio. This is just a placeholder for now while I develop an actual nice looking portfolio. Below is how I did it.


  • If you need a free domain use https://digitalplat.one/

  • Once you have your domain create your base HTML and CSS files, or use a website builder and copy the html and css (or even JS if your fancy) into their respective places

  • If you want to self-host using your own hardware you can! You will have to add DNS records to your domain using Digital Plat One's DNS editor. In there you will add A class records pointing to your IP address.

  • Or if you want it to be hosted for you use either vercel or netlify.app, both of these sites offer free/hobbyist plans

  • I suggest you upload your files to a GitHub repo. If not you can upload them manually

  • Create your project on the site and add your repo and it will be built into a working project

  • Lastly add your domain to the site! If your using vercel its done very simply by adding a domain to your project and typing it in. It will instruct you for entering the right DNS records. Netlify should follow a similar process.

  • If you really want, you can route your domain traffic through cloudflare for additional protection, for that you will transfer your domains nameservers over to cloudflare and change its DNS records there.

  • If you get stuck there is many resources availible for this process.
